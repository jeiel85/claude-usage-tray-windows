Android 앱 · AI 사용량

자리를 비워도,
한도는 주머니 속에.

QR 한 번이면 PC와 휴대폰이 연결됩니다. 집 PC와 회사 PC가 같은 계정이면 한 카드로 묶어 보여 주고, 다른 계정은 절대 섞지 않습니다.

  1. PC에서 QR 띄우기트레이 팝업 ⚙ 설정 → 연결 → 휴대폰 연결… (QR 표시)
  2. 휴대폰으로 스캔앱의 + PC 추가로 찍습니다. 앱이 없으면 기본 카메라로 찍어도 설치 안내가 열립니다.
  3. 끝사용량은 바뀔 때마다 실시간으로, 알림도 자동으로 연결됩니다.
  • 계정 단위로 묶기PC 3대, 계정 2개면 카드 2장.
  • 밖에서도 연결같은 Wi-Fi · Tailscale · Cloudflare Tunnel.
  • 알림센터지난 알림을 30일 동안 다시 보기.
  • 앱 자동 업데이트새 버전을 받아 SHA-256 확인 후 설치.
Android 앱 받기APK · Android 8.0 이상

Google Play 출시를 준비하고 있습니다. iPhone 앱은 없지만 ntfy 앱으로 알림은 받을 수 있습니다.

설치

1분이면 충분합니다.

STEP 1

받기

ClaudeUsageTray.exe 하나면 됩니다. 설치 과정 없이 실행 파일 그대로.

STEP 2

실행

SmartScreen 경고가 뜨면 추가 정보 → 실행. 앱이 반응하지 않으면 .NET 9 Desktop Runtime을 먼저 설치하세요.

STEP 3

트레이 아이콘 클릭

작업 표시줄 오른쪽의 게이지 아이콘을 누르면 팝업이 열립니다. Windows 시작 시 자동 실행도 켤 수 있습니다.

필요한 것

  • Windows 10 이상
  • .NET 9.0 Desktop Runtime (없으면 앱이 실행되지 않습니다)
  • 쓰는 도구(Claude Code, Codex, Antigravity 등)에 로그인된 상태
  • 휴대폰 앱: Android 8.0 이상 · 알림은 ntfy 같은 UnifiedPush 앱

FAQ

자주 묻는 질문

공식 앱인가요?

아니요. Anthropic, OpenAI, Google과 관련 없는 개인 오픈 소스 프로젝트입니다. 각 도구가 공개하거나 앱에서 쓰는 사용량 정보를 읽어 보여 줍니다.

제 로그인 정보는 안전한가요?

앱은 각 도구가 PC에 저장해 둔 로그인 정보를 읽어 그 서비스의 사용량 조회에만 씁니다. 개발자 서버로 보내지 않고, 휴대폰에도 토큰이나 계정 ID를 보내지 않습니다. 코드는 모두 공개돼 있습니다.

Windows가 "PC 보호" 경고를 띄워요.

코드 서명 인증서가 없는 개인 프로젝트라 SmartScreen이 경고합니다. 추가 정보 → 실행을 누르면 됩니다. 릴리스마다 SHA256.txt가 함께 올라가니 파일을 직접 확인할 수도 있습니다.

집 PC와 회사 PC 사용량을 합쳐 볼 수 있나요?

네. 설정 → 연결에서 한 PC의 동기화 코드를 다른 PC에 붙여 넣거나, OneDrive 같은 공유 폴더를 지정하면 같은 계정의 사용량이 합쳐집니다. Claude Code가 없는 PC에서도 그룹의 사용량을 볼 수 있습니다.

밖에서도 휴대폰으로 볼 수 있나요?

네. Tailscale을 쓰거나, 설정 → 연결에서 Cloudflare Tunnel을 켜면 됩니다. 포트 개방이나 방화벽 설정이 필요 없습니다.

iPhone은요?

휴대폰 앱은 지금 Android만 있습니다. iPhone에서는 ntfy 앱으로 토픽을 구독하면 같은 알림을 받을 수 있습니다(설정 → 알림 → ntfy).

오늘 한도, 지금 얼마나 남았을까요?

추측은 그만. 트레이를 한 번 보세요.
